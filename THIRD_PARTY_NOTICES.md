### Modification of toml++

`third_party/toml++/toml.hpp` differs from the toml++ v3.4.0 release in one
function, `toml::impl::is_non_ascii_horizontal_whitespace()`:

- v3.4.0 ends the `switch` in that function with `default: TOML_UNREACHABLE;`
  and a second `TOML_UNREACHABLE` after it. The bitmask test before the
  `switch` lets three ranges through to it but the `switch` handles only two,
  so any character of U+00A1..U+0499, U+2C5E..U+3057 (except U+3000) or
  U+FB26..U+FEFE in a bare key or a table header reached the unreachable
  marker: undefined behavior. It was found by fuzzing Yuzen's input reader
  (`yuzen/tests/fuzz/`).
- In this copy the default case returns `false` (none of those characters is
  whitespace) and the trailing marker is removed.

The change is marked in the file twice: in the license header at the top
("MODIFIED FOR YUZEN") and by a comment beginning `Yuzen:` at the change. It is
offered under the same MIT License as the rest of the file. The upstream
`master` branch of toml++ has since made the same change (its
`impl/unicode_autogenerated.hpp` returns `false` in the default case), but no
release contains it yet; when one does, this copy can be replaced by the
unmodified release. `yuzen/tests/test_config.cpp` holds the regression test.

compiled Yuzen binary should ship this file and the license texts of Eigen

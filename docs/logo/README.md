# Yuzen — logo

A Y coated in a celadon glaze, lit from the upper left. The glaze has drained
into a thicker, darker run down the right arm and the right side of the stem,
and the highlight on the left arm is its smooth free surface: a liquid film
whose thickness varies over the surface, which is what Yuzen computes. For the
full specification, see `yuzen-logo-spec.png`.

## What to use

| Situation | File |
|---|---|
| Default (light background) | `yuzen-mark.svg` |
| Dark background | `yuzen-mark-reversed.svg` |
| Shown with the name | `yuzen-lockup-h.svg` / `yuzen-lockup-v.svg` (`yuzen-lockup-h-reversed.svg` on dark) |
| Below 32px | `yuzen-mark-solid.svg` |
| Favicon | `favicon.ico` (16 / 32 / 48 included) |
| Two flat tones, no gradient (screen printing, embroidery) | `yuzen-mark-flat.svg` |
| Single-color print and engraving | `yuzen-mark-1color.svg` |
| Grayscale | `yuzen-mark-mono.svg` |
| Animated (the run flows down) | `yuzen-mark-animated.svg` / `.gif` |

Pre-rendered rasters are in `png/` (mark 64–1024px, icon 16–48px,
horizontal lockup 400–1600px, vertical lockup 800px). The icons crop the
clear space to a thin margin, and below 32px they use the solid mark.

## Rules

- **Clear space** is about one arm width on all four sides. It is already
  built into the SVG `viewBox`, so placing the file as-is gives the specified
  spacing.
- **Minimum size** is 32px for the full mark. Below that the highlight and the
  run blur into the gradient, so substitute `yuzen-mark-solid.svg`.
- **The highlight sits on the left arm and the run on the right.** Never
  mirror the mark.
- Do not change the aspect ratio, and do not draw the gradient, the
  highlight or the run separately from the letter.

## Colors

| | | |
|---|---|---|
| Glaze, light | `#B5D7C5` | Gradient start, top left of the letter |
| Glaze, deep | `#1F5644` | Gradient end, foot of the stem |
| Run, top | `#618E81` | The darker glaze, top of the right arm |
| Run, foot | `#346A69` | The darker glaze, foot of the stem |
| Highlight | `#FFFFFF` at 20 % | Along the left arm |
| Celadon | `#5E8C78` | The solid mark, and the accent color of the manual |
| Shadow | `#3C5F4E` | The run in the flat mark |
| Sumi | `#22201D` | Logotype, single-color mark |
| Paper | `#F4F1EA` | Background |
| Kiln | `#2B211B` | Dark background |

`yuzen-mark-amber.svg` and `yuzen-mark-lapis.svg` carry the same glaze in
amber and in lapis. On a dark ground the glaze is lifted
(`yuzen-mark-reversed.svg`), so that the foot of the stem stays clear of the
background.

## Logotype

Bitstream Charter Bold, embedded as outlines. The font itself is not
included, so obtain it separately if the type needs to be reset.

## Regenerating

Every file here is generated by `make_logo.py` from one geometry: the outline
of the Y is built from straight edges and circular arcs, and the colors are
set at the top of the script. Change them there and run

```sh
python3 docs/logo/make_logo.py --raster
```

which rewrites the SVGs, `png/`, `favicon.ico`, the GIF and the manual's
`docs/manual/figures/yuzen-mark.pdf` and `yuzen-lockup-h.pdf`. It needs
cairosvg and Pillow, and rsvg-convert (librsvg) for the GIF.

## Use in a README

```markdown
<img src="docs/logo/yuzen-lockup-h.svg" alt="Yuzen" height="64">
```

If you place the animated version, note that GitHub's SVG sanitizer
sometimes strips `<animate>`, so `yuzen-mark-animated.gif` is more reliable.
